이전 중복 샘플 네 씬은 정리했습니다. 현재 씬 경로와 GUID는 유지해 기존 이동·저장 참조를 보존합니다.
## 초기 농장과 NPC 상점

`Assets/Scenes/FirstGarden.unity`를 열어 편집하고 Play합니다. 현재 씬에 초기 농장을 적용하는 도구는 Tools > Everything Grows > Set up starter farm and shop입니다.
현재 농장은 집 한 채, 5×3칸의 경작된 밭, 집 옆 상인으로 구성합니다. 기존 테스트용 길과 바닥 아이템 계층은 비활성 상태로 보관합니다.
상인 가까이에서 **E**를 누르면 상점이 열립니다. **Buy**로 구매하고, 상점이 열린 동안 **핫바 아이템 우클릭**으로 한 개씩 판매합니다. 이때 우클릭은 인벤토리 칸을 뜯지 않습니다.
**E / Esc / Close**로 닫습니다. 시작 골드는 기본 100이며 재고는 제한 없이 구매 가능합니다. 골드 또는 인벤토리 공간이 부족하면 구매하지 않습니다.

**Tools > Everything Grows > NPC manager**에서 현재 씬의 NPC별 설정을 수정합니다.

- Starting Gold: 플레이 시작 골드.
- Npcs: NPC 프로필 목록. Id는 씬의 ShopNpc > Npc Id와 일치시킵니다.
- Offers: NPC별 판매 물품과 Buy Price, Sell Price. Sell Price가 -1이면 아이템 기본 판매가를 사용합니다.
- 모든 아이템 기본 판매가: 상점 목록에 없는 아이템도 포함하여 설정합니다. 성장한 엑스칼리버/총도 판매할 수 있습니다.
- NPC 설정과 가격 저장: 씬 설정과 아이템 자산을 저장합니다. 설정은 Play 밖에서 수정합니다.

NPC 추가는 맵 배치 창의 Npcs > Merchant 프리팹으로 합니다. NPC마다 고유한 Id와 프로필을 지정하면 서로 다른 상점을 사용할 수 있습니다.
집은 Farmhouse 프리팹으로 직접 이동·배치할 수 있습니다. 하단 몸체 영역은 이동과 경작을 막고 앞의 파란 발판에서 E로 실내에 진입합니다. 수확 후 다시 설치한 집도 출입할 수 있습니다. 나올 때는 들어갔던 집 앞으로 돌아옵니다. 실내 배치·NPC 설정은 [건물 내부 안내](Docs/BUILDING_INTERIORS.md)를 참고합니다.
StartingPlot이 붙은 바닥은 Play 때 경작된 밭으로 초기화합니다. 새로 만든 집 이미지의 생성 기록은 Docs/ART.md에 있습니다.

작업 폴더: `C:/Users/MSI/wtf`. Unity 6000.3.25f1, 2D 탑뷰, Built-in 렌더링.
현재 열린 `Assets/Scenes/FirstGarden.unity`에 편집용 맵을 연결했습니다. 이 씬에서 직접 배치하고 Play합니다. 씬에 저장된 `EditableMap` 배치를 그대로 사용합니다. 배치가 없는 초기 샘플만 실행 시 기본 필드를 생성합니다.

## 첫 플레이 — 기본 작물 농사

시간 기반 작물 농사는 현재 농장인 `Assets/Scenes/FirstGarden.unity`에서 사용합니다. 현재 씬에 씨앗을 추가하려면 Tools > Everything Grows > Set up crop farming을 실행합니다.

1. 집 옆 상인에게 E로 말을 걸어 괭이·물뿌리개·씨앗을 구매합니다.
2. 괭이를 선택하고 좌클릭으로 한 칸씩 경작합니다. 맨손으로는 땅을 팔 수 없습니다.
3. 씨앗을 선택하고 빈 밭을 가리킨 뒤 E를 누릅니다. 씨앗은 한 개씩 소비됩니다.
4. 물뿌리개로 한 번 물을 주면 성장하기 시작합니다. 심기 전에 물을 줘도 됩니다.
5. 설정된 시간이 지나면 성숙합니다. E로 수확하며, 토마토는 수확 후 다시 물을 주면 재성장합니다.
6. 상점에서 인벤토리를 우클릭해 수확물을 한 개씩 판매합니다. 씨앗과 작물은 같은 종류끼리 슬롯에 쌓입니다.

기본 성장 시간: 파스닙 20초, 감자 30초, 콜리플라워 60초, 토마토 55초(재수확 20초).
날짜·계절·잠자기·에너지 시스템은 없습니다. 별도의 낮밤 밝기 주기는 아래 설정을 따릅니다. 물을 주지 않으면 성장하지 않으며, 성장 도중 물이 자동으로 마르지는 않습니다.
작물별 Growth Seconds, Regrow Seconds, 수확 결과와 판매가는 Assets/Resources/Crops의 PlantDefinition에서 수정합니다. Regrow Seconds가 0이면 단일 수확 작물입니다.
비료·품질 등급·날씨·물뿌리개 물통·스프링클러·도구 강화·거대 작물은 아직 구현하지 않았습니다.

## 조작

- WASD: 이동. 카메라는 플레이어를 따라갑니다.
- 좌클릭: 선택 도구 사용 / 무기 공격. 심기는 하지 않습니다.
- 우클릭: 바닥 물건·구름 획득 / 성장 중인 대상 회수 / 핫바 칸 뜯기.
- F: 가까운 땅에 괭이·물뿌리개 사용.
- E: 씨앗/물건 심기 / 성숙한 대상 수확 / 상점 / 집 정문 앞에서 다음 날로 이동.
- Shift: 이동 방향으로 회피. 멈춰 있으면 마우스 방향으로 회피.
- 1~9 / 마우스 휠 / 핫바 클릭: 선택. Q: 물건 내려놓기.
- R: 뜯은 핫바 칸을 다시 붙임. Tab: 인벤토리. M: 전체 필드 위치 지도.

## 현재 규칙과 범위

- 하나의 연속된 약 49×33칸 필드. 전투 입장 메뉴, 별도 전투 씬, 스테이지 전환이 없습니다.
- 중앙 안전 구역: x ±6.5, y ±4.5. 노란 경계 표시가 있으며 막는 울타리는 없습니다.
- 바깥에서도 경작과 식재가 가능하지만 적의 공격을 받을 수 있습니다.
- 적은 공격 전 예고 후 근접 공격 또는 고정 방향 투사체를 발사합니다. 탄환은 발사 후 플레이어를 추적하지 않습니다.
- 적을 처치하면 검/활 재료를 떨어뜨립니다. 적은 25초 후 플레이어가 충분히 떨어져 있으면 재등장합니다.
- 엑스칼리버/총은 다시 심을 수 없습니다. 수확은 밭을 비우며 인벤토리가 가득 차면 수확물이 발밑에 떨어집니다.
- 현재 무기 데이터: `Assets/Resources/Equipment`. 성장 시간, 수확 결과, 변화 완료 여부, 피해, 사거리, 공격 간격을 Inspector에서 조절합니다. 무기 등 기존 실험 대상은 초 단위 성장을 유지하고, 일반 씨앗은 일 단위로 자랍니다.
- 기존 도구·구름·보관 칸·돌의 자동화 효과는 이전 시제품의 임시 검증 기능으로 유지합니다.
- 솔로 테스트에서 쓰러지면 아이템을 보존한 채 농장으로 돌아옵니다. 시체 식재 부활, NPC, 멀티플레이, 저장·불러오기는 아직 구현하지 않았습니다.
- 무기와 적 그림은 코드로 만든 임시 픽셀 그래픽입니다. 최종 B급 연출과 미술은 다음 단계입니다.

설계: [Docs/GAME_DESIGN.md](Docs/GAME_DESIGN.md). 후보 목록: [Docs/CONTENT_CANDIDATES.md](Docs/CONTENT_CANDIDATES.md).
기존 픽셀 이미지 생성 기록: [Docs/ART.md](Docs/ART.md).

## 검증

별도의 임시 Unity 프로젝트에서 `OpenFieldCheck.Run`으로 농사 회귀 검사, 무기 변환과 수확, 재식재 제한, 안전 구역, 공격 재사용 간격, 근접/투사체 처치, 피할 수 있는 적 탄환, 회피, 체력 회복, 사망 후 아이템 보존을 검사합니다.
`OpenFieldPlayCheck.Run`은 격리 프로젝트의 실제 Play 모드 초기화 및 실행 오류를 확인합니다. 사용자 씬에서 이 검증을 실행하지 마세요.

## Unity에서 직접 맵 배치하기

Play를 끈 상태에서 `Assets/Scenes/FirstGarden.unity`를 엽니다. Hierarchy의 `Farm > EditableMap`에서 수정합니다.

| 계층 | 편집 방법 |
|---|---|
| Ground | 바닥 타일 이동·복제·삭제. `FarmGround > Can Farm`으로 경작 가능 여부 설정 |
| Paths | 길 타일 이동·복제·삭제. 길은 시각 표시이며 경작 허용 여부는 아래 Ground가 결정 |
| Decoration | 꽃·나무 등 시각 장식. 현재 장식은 통과 가능 |
| Items | 아이템 이동·복제·삭제. `FarmItemPlacement > Item`에 원하는 PlantDefinition 지정 |
| EnemySpawns | 적 시작 위치 이동·복제·삭제. `EnemyPlacement > Ranged` 체크 시 원거리 적 |
| Regions/WorldBounds | 이동 가능한 전체 영역. Transform Position으로 중심, Scale X/Y로 폭·높이 설정 |
| Regions/SafeArea | 안전 구역. Transform Position과 Scale X/Y로 위치·크기 설정 |
| Regions/PlayerSpawn | 플레이어 시작·사망 후 복귀 위치 |

`Assets/Prefabs/Map`의 프리팹을 해당 계층에 드래그해 추가하고 Ctrl+D로 복제할 수 있습니다.
바닥을 넓힐 때는 Ground 타일 추가와 WorldBounds 확장을 함께 합니다. 구역과 바닥은 회전하지 않고 XY 평면에서 배치합니다.
적 출현 지점을 SafeArea 안에 넣으면 그 적은 생성되지 않습니다. PlayerSpawn은 WorldBounds와 SafeArea 안에 두는 것을 권장합니다.
수정 후 Ctrl+S로 씬을 저장하고 Play합니다. Play 중 변경한 값은 정지하면 돌아가므로 배치는 Play 밖에서 수정합니다.
이미 변환된 맵에는 생성 메뉴가 덮어쓰지 않습니다. 초기 씬에 배치가 없다면 `Tools > Everything Grows > Make current map editable`로 한 번 생성합니다.
프리팹 미리보기용 아이템·적·플레이어 그림은 Play 중 숨기고 실제 게임 객체를 해당 위치에 생성합니다. 바닥·길·장식은 씬 객체를 그대로 사용합니다.

## 씬 배치 도구 창

메뉴 **Tools > Everything Grows > Map placement**를 열면 `맵 배치` 창이 나옵니다. 필요하면 탭을 드래그해서 Scene/Hierarchy 옆에 도킹하세요.

1. 목록에서 바닥·길·장식·아이템·적 프리팹을 선택합니다. 배치 중 프리팹을 바꾸면 배치 상태가 유지됩니다.
2. 격자 맞춤과 배치 크기를 정하고 **배치 시작**을 누릅니다.
3. Scene을 클릭하면 지정 계층에 프리팹이 추가됩니다. 바닥과 길은 드래그로 연속 배치할 수 있습니다.
4. Shift+클릭/드래그는 선택한 프리팹 종류와 관계없이 커서 아래 맨 위에 보이는 배치 오브젝트를 삭제합니다. 겹친 대상은 한 번에 하나씩 지우며, 큰 오브젝트는 중심이 아닌 가장자리에서도 삭제할 수 있습니다. 같은 위치에도 겹쳐 배치할 수 있으며, 새로 배치한 블록은 해당 계층의 기존 블록 위에 표시됩니다.
5. **Esc 또는 배치 종료**로 일반 선택/이동 모드로 돌아갑니다. **Ctrl+Z**로 한 번의 배치/삭제 작업을 취소할 수 있습니다.
6. 맵 경계·안전 구역·시작 위치 버튼은 해당 오브젝트를 선택하고 Scene에서 보여줍니다.
7. 선택한 아이템의 Item 또는 적의 Ranged를 Inspector에서 바꾸면 미리보기 그림도 갱신됩니다.
8. **씬 저장 또는 Ctrl+S**로 저장합니다. Play 중에는 배치 도구가 비활성화됩니다.

맵 경계 밖으로 바닥을 추가했다면 WorldBounds도 함께 넓혀야 실제로 이동하고 경작할 수 있습니다. 일반 오브젝트 수정에는 기존 Unity의 W(이동), E(회전), R(크기), Ctrl+D(복제)를 사용합니다. 바닥/구역은 XY 축에 맞춰 배치하며 회전은 사용하지 않습니다.

## HP 하트 수확

왼쪽 상단 HP는 기본 5개의 하트이며 한 칸은 20 HP입니다. 하트에 마우스를 올리고 E를 누르면 한 번에 하나만 인벤토리에 들어가고 최대 HP가 한 칸 줄어듭니다. 인벤토리에 공간이 없고 기존 하트 묶음도 없으면 발밑에 떨어집니다. 마지막 한 칸도 수확할 수 있으며, 마지막 하트를 수확하는 즉시 게임오버가 됩니다. 게임오버에서는 이동·전투·성장·상점 조작이 멈추고 자동 복귀하지 않습니다. 다시 하려면 Play를 정지한 뒤 재시작합니다.
하트를 선택한 뒤 가까운 땅을 가리켜 좌클릭하면 한 칸을 다시 붙입니다. 하트도 E로 밭에 심고 물을 줘서 키울 수 있습니다.
OpenFieldCombat의 Starting Hearts와 Health Per Heart에서 초기 칸 수와 칸당 체력을 설정합니다. 피해·안전 구역 회복·사망 복귀는 현재 남은 최대 HP를 따릅니다.

## 집 수확과 심은 물건의 표시

집 가까이에서 마우스로 집을 가리키고 E를 누르면 집 아이템을 수확하며 원래 집과 충돌 판정이 사라집니다. 밭에 심고 물을 주면 15초 뒤 큰 집 아이템으로 자랍니다. 성장 중과 성숙 후 모두 작게 표시되며 자동 설치되지 않습니다. E로 수확해 인벤토리에 받은 뒤 집을 선택하고 좌클릭해 원하는 위치에 직접 설치합니다. 설치 미리보기는 가능한 위치는 초록색, 불가능한 위치는 빨간색입니다. 경작지가 아니어도 설치할 수 있으나 건물·심은 물건·플레이어·방문 NPC와 겹치는 자리는 막습니다.
집을 설치하거나 수확해도 소지품 인벤토리 칸수는 변하지 않습니다. 큰 집은 다시 설치하거나 심을 수 있지만 추가 변형은 없습니다.
집 데이터는 Assets/Resources/Buildings의 House, UpgradedHouse에서 성장 시간·수확 결과·설치 크기·판매가를 조절합니다.
모든 심은 물건은 공통 싹 대신 해당 아이템의 원래 그림을 사용하며 아래쪽 30%가 땅에 묻힌 모습으로 표시합니다. 성장 중에는 최대 1칸 이내로 크기를 제한합니다. PlantDefinition의 Planted Display Size(성장 중 표시 크기), Mature Display Size(성숙 후 크기), Item Sprite(그림)로 설정합니다.

## 낮밤과 방문 상인

날짜 계산 없이 낮 → 저녁 → 밤 → 새벽을 반복합니다. 기본 시간은 각각 180초 / 30초 / 120초 / 30초입니다. 저녁에는 점점 어두워지고 새벽에는 밝아집니다. UI는 어두워지지 않습니다.
상인은 낮에만 표시되고 거래할 수 있습니다. 저녁이 시작되면 떠나며 열려 있던 상점도 닫힙니다. 다음 낮에 다시 방문합니다. 몬스터는 기존 안전구역 밖 배치 지점에서 저녁부터 등장하고 새벽에 사라지며, 다음 저녁에 다시 등장합니다. 새벽에는 적 탄환도 제거됩니다.
Assets/Resources/WorldCycle.asset을 선택해 Daylight Seconds, Dusk Seconds, Night Seconds, Dawn Seconds와 Night Darkness를 조절합니다. 작물은 낮밤과 관계없이 성장합니다. 싱글플레이에서 인벤토리·상점·대화창·지도를 열면 게임 시간이 멈춥니다. 게임오버에서는 밝기 주기도 멈춥니다.

## 기본 지급과 인벤토리 UI

시작 시 괭이 1개, 물뿌리개 1개, 파스닙 씨앗 10개, 낫 1개를 지급합니다. Assets/Resources/StartingInventory.asset에서 물품과 수량을 설정합니다.
HP 하트만 왼쪽 위에 표시하며 HP 숫자·킬 수·하트 아래 설명과 상시 정보판은 표시하지 않습니다. 하트에 마우스를 올리고 E로 하나씩 수확하는 기능은 유지합니다.
Tab으로 인벤토리를 열고 닫으며 보유 골드는 인벤토리 안에서만 확인합니다. 인벤토리에서는 아이템 그림과 수량을 확인하고 클릭해 선택합니다. 상점을 열면 옆에 인벤토리가 함께 표시되고 우클릭으로 한 개씩 판매합니다. 인벤토리를 보는 동안 낮밤·작물·전투 시간은 멈추고 창을 닫으면 이어집니다.

일반 몬스터의 근접 공격과 탄환은 한 번에 하트 반 칸(기본 10 HP)을 깎습니다. 하트는 가득 참 / 반 칸 / 빈 윤곽선으로 표시하고, 회복 중에도 표시를 반 칸 단위로 맞춥니다.

모든 수확물은 인벤토리에 공간이 있으면 바로 들어가고, 꽉 차면 플레이어 발밑에 아이템으로 떨어집니다. 기존 묶음에 합칠 수 있으면 새 칸 없이 들어갑니다. 땅에 떨어진 물건은 우클릭으로 줍습니다.

## 맵 이동과 자동 저장

맵별 밭·성장·드롭·집 상태를 유지하고 맵 이동 때 자동 저장합니다. 출입구와 도착 지점은 씬에 프리팹으로 배치합니다. 설정 방법과 저장 범위는 [MAP_TRAVEL_AND_SAVES.md](Docs/MAP_TRAVEL_AND_SAVES.md)를 참고하세요.

## 이동과 장애물

벽·바위 등에 MapObstacle을 붙여 이동과 탄환을 막습니다. 씬 배치와 판정 설정은 [MOVEMENT_AND_OBSTACLES.md](Docs/MOVEMENT_AND_OBSTACLES.md)를 참고하세요.

## 전투 테스트 맵

농장에서 마을로 이동한 뒤 마을 동쪽 입구로 CombatTest 맵에 들어갑니다. 기둥·엄폐물과 근접·원거리 몬스터를 배치했습니다. [플레이 및 씬 편집 방법](Docs/COMBAT_TEST_MAP.md)을 참고하세요.

## 농장·마을·던전 기본 월드

농장 ↔ 마을 ↔ 던전, 마을 ↔ 잡화점 내부를 연결했습니다. 마을의 주민과 대화하고 잡화점에서 기존 물품을 거래할 수 있습니다. 씬 편집과 NPC 설정은 [WORLD_FRAMEWORK.md](Docs/WORLD_FRAMEWORK.md)를 참고하세요.

## 데모 개발 기준

입대 전 데모의 작업 목록과 현재 진행 상황은 [DEMO_ROADMAP.md](Docs/DEMO_ROADMAP.md)에 기록합니다. 최종 맵 배치와 이동 동선은 사용자 그림을 받은 후 적용합니다.

기본 조작과 메뉴 일시정지 규칙은 [FOUNDATION_CONTROLS.md](Docs/FOUNDATION_CONTROLS.md)에 정리했습니다. 배치 후 `Tools > Everything Grows > World > Validate world connections`에서 연결 오류를 확인할 수 있습니다.

## 사용자 맵 초안

길드(북서)·대장간(북동)·광장(중앙)·주택/상점(남서)을 기준으로 마을을 배치하고 남쪽 해안과 가벼운 조경을 추가합니다. 위치 기준과 원본 그림은 [MAP_LAYOUT_PLAN.md](Docs/MAP_LAYOUT_PLAN.md)에 보관합니다.
