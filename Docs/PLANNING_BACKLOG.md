# 보류 중인 기획 항목

> 2026-10-27 변경: 안전 농장·층별 탑 중심 진행을 자유 거점+필드 보스 방향으로 대체한다. 일반 몬스터는 낮 스폰 예정. 최신 규칙과 현재 적용 범위는 FREE_CAMP_RECOVERY.md를 우선한다.

2026-10-16 대화 기준. 아래 항목은 나중에 논의하기 위해 저장한 목록이다. 지금 세부 규칙을 확정하거나 구현을 시작하지 않는다. 목록의 순서는 개발 우선순위가 아니다.

## 최근 합의한 방향

- 핵심은 무엇이든 심고 그 변화와 활용을 발견하는 것이다.
- 농사로 성장하면 심을 수 있는 대상의 종류가 큰 단계별로 넓어진다. 구체적인 단계와 제한 방식은 미정이다.
- 농장은 안전하게 농사와 실험을 즐기는 공간으로 두고, 전투를 별도로 즐기는 방향이다. 농장으로 몰려오는 강제 웨이브는 현재 방향으로 사용하지 않는다.
- 전투는 층 단위로 내려가는 던전을 구상한다. 일정 층마다 보스 스테이지가 있으며 돌파하면 특수한 아이템이나 장비를 얻는다. 전체 규모와 보스 간격은 미정이다.
- 던전의 돌파 조건, 중간 시작 지점, 귀환, 사망 손실, 보스 반복 보상은 논의를 보류했다.
- 이 방향은 기획 합의이며 현재 시제품에 구현됐다는 뜻이 아니다. GAME_DESIGN.md에 남은 오픈필드 시제품 설명과 구분한다.

## 보류 1. 시작 시 심을 수 있는 범위와 첫 해금

- 처음부터 심을 수 있는 대상의 범위.
- 첫 성장 단계 이후 열리는 대상의 범위.
- 초반에 게임의 특이함을 보여줄 예외 아이템.
- 구체적인 분류와 아이템 목록은 미정.

## 보류 2. 농사 경험치와 성장 방식

- 심기, 재배 완료, 수확 중 어떤 행동에 경험치를 주는지.
- 새로운 물건의 첫 재배에 보너스를 주는지.
- 같은 물건의 반복 재배가 성장에 얼마나 기여하는지.
- 레벨 또는 성장 단계의 조건과 필요 경험치는 미정.

## 보류 3. 심은 결과물의 기본 변화 규칙

- 물건 자체가 변하는 경우.
- 여러 물건을 생산하는 경우.
- 수확하지 않고 심어진 상태에서 기능하는 경우.
- 이미 변화한 물건을 다시 심었을 때의 처리.
- 기존에 논의한 추가 변환 없음 원칙을 바탕으로 실제 식재 허용과 예외를 구체화할 필요가 있다.

## 보류 4. 반복 재배의 활용처

- 판매해서 돈을 버는 물건.
- 사용하면 소모돼 다시 필요한 물건.
- 여러 개 배치하거나 보유할 가치가 있는 물건.
- 한 번 발견하는 것으로 충분한 물건.
- 각 역할을 어떤 물건에 배정할지는 미정.

## 보류 5. 첫 플레이용 최소 콘텐츠 목록

- 평범한 작물.
- 실용적인 변형 물건.
- 황당한 예외 물건.
- 우선 소수의 사례만 구체화하는 안을 검토했다. 8~12개는 제안된 규모이며 확정 수량이 아니다.

## 진행 원칙

지금은 위 항목의 해답이나 구현 순서를 정하지 않는다. 이후 사용자가 해당 기획을 다시 논의할 때 이 목록을 기준으로 이어간다.


## 2026-10-21 데모 계획 연결

입대 전 싱글플레이 30~60분 데모의 작업 목록은 [DEMO_ROADMAP.md](DEMO_ROADMAP.md)에 저장했다. 심을 대상 8~12개와 특수 변화 3~5개는 이번 데모의 작업 목표로 잡았으며 구체적인 명단은 아직 정하지 않았다. 상세 해금·경험치·던전 진행 규칙은 이 문서의 보류 상태를 유지한다. 최종 맵 배치와 동선은 사용자 그림을 기다린다.


## 2026-10-23 시점과 하늘 소재

- 현재 2D 탑뷰 시점을 유지한다.
- 하늘이 보이는 특정 장소를 두고 구름·달 같은 소재를 획득하는 방향으로 논의했다.
- 장소 배치, 획득 조작/조건, 변형 결과는 미정이며 이번 농사 표시 개선에서는 구현하지 않는다.
- 추가 구조 정리 중 저장·복원 처리 확장, 입력/UI 추가 분리는 사용자 판단으로 보류한다.

## 2026-10-23 농사 레벨 구현 승인

사용자 확인 후 수확 경험치·레벨·아이템별 필요 레벨과 저장/UI 기반을 구현했다. 이 부분은 위의 보류 1·2에서 해제한다. 모든 기존 아이템의 필요 레벨은 1로 유지한다. 어떤 물건을 어느 레벨에서 해금할지와 실제 밸런스는 아직 미정이다. 구체적인 동작/설정은 FARMING_LEVELS.md 참조.
