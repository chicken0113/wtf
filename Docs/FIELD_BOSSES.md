# 필드 보스 전투·재등장 기반

2026-10-27 승인 범위.

## 설정과 임시 보스
- 몬스터 관리에서 보스를 켜면 추적 범위(bossLeashRange), 처치 후 재등장 초(bossRespawnSeconds)를 설정할 수 있다.
- 추적 범위는 고정 배치 위치를 중심으로 잰다. 발견 범위/기존 공격력·속도·예고·간격은 같은 MonsterType의 기존 수치를 재사용한다.
- Resources/Monsters/FieldBoss는 Chaser의 기존 외형·공격·보상을 사용하는 임시 보스다. 초기 추적 범위 12, 재등장 120초. 전용 패턴·보상은 추가하지 않는다.
- Prefabs/Map/FieldBossSpawn을 씬의 FarmMapLayout 아래에 배치하면 사용할 수 있다. 위치와 MapObjectId는 배치별로 고유해야 한다. 보스는 지역 스폰 최대 수에 포함되지 않는다.
- 이번 작업에서 BossFoundationSetup으로 숲(ForestClearing)에 한 마리를 한 번 추가했다. 이후 에디터 시작/컴파일 때 재생성하지 않는다. 기존 보스가 있으면 재배치하지 않는다. 숲 자체가 수정 중이면 보류한다. 다른 활성 씬의 변경은 저장/닫지 않는다. 사용자가 만든 기존 오브젝트를 다시 생성하지 않는다.
- 지역 저장이 이미 있는 상태에서 새로 배치한 보스도 저장에 없다는 이유로 사라지지 않는다.

## 전투·초기화
- 플레이어를 발견하거나 공격받으면 교전하며, 교전 중에는 발견 범위보다 멀어져도 추적 범위 내에서는 계속 싸운다.
- 플레이어 또는 보스가 고정 위치 기준 추적 범위를 벗어나면 HP·공격 예고·경직·이동 경로·야간 도발 상태를 초기화한다. 보스 자신의 탄환만 취소한다. 다른 적/플레이어의 탄환은 유지한다.
- 도주 초기화 후 원래 위치로 걸어 돌아가며 귀환 중에는 공격하지 않고 피해를 받지 않는다. 귀환 중 밤이 되면 고정 위치에서 귀환을 마치고 잠든다.
- 플레이어 사망 또는 다른 맵 이동은 살아 있는 보스들을 즉시 고정 위치로 돌려놓고 초기화한다. 이미 처치한 보스의 타이머는 바꾸지 않는다.
- 밤의 수면/공격받은 보스의 즉시 각성 규칙은 그대로다. 밤에 초기화하면 다시 잠든다.
- 초기화는 처치가 아니므로 보상을 주지 않는다. 실제 처치 보상은 기존 EnemyDefeated 경로에서 한 번만 지급한다.

## 재등장·저장
- 처치 시 GameSession.WorldSeconds + bossRespawnSeconds를 재등장 시각으로 기록하고 기존 처치 저장과 함께 저장한다.
- 다른 맵에서도 게임 내 시간이 흐르는 만큼 대기 시간이 지난다. 메뉴 일시정지·게임 종료 중 현실 시간은 계산하지 않는다.
- 시간이 끝나도 밤에는 재등장하지 않는다. 다음 낮에 해당 맵이 활성화되면 고정 위치에서 최대 HP로 재등장한다.
- MapSave.regionalEnemies의 optional bossRespawnAt/bossEngaged/bossReturning 필드를 사용하고 저장 버전 1을 유지한다.
- 예전 저장의 죽은 보스에 타이머가 없으면 새 대기 시간을 한 번 부여한다. 맵 이동/재실행으로 대기 시간을 반복 초기화하지 않는다.
- 이 보스 기반은 SpawnRegion이 연결된 오픈필드에 적용한다. 기존 비지역 탑/훈련장 동작은 바꾸지 않는다.

## 코드와 검사
- EnemyCombatSystem.Bosses: 교전 수명·귀환·초기화·재등장. 기존 개체 이동/공격은 EnemyCombatSystem을 재사용한다.
- ProjectileSystem.SpawnOwned/ClearOwner: 탄환 발사자 식별과 초기화 시 취소. 탄환 명중 처리 중 플레이어가 사망해도 목록을 즉시 삭제하지 않아 반복 중 인덱스가 깨지지 않는다.
- GameSession.Travel/RespawnAfterDeath: 출발 저장 전에 살아 있는 보스 초기화.
- FieldBossCheck.Run: 임시 프로젝트/별도 저장에서만 배치 중복 방지, 도주/귀환, 야간 각성/초기화, 보상 중복 방지, 다른 맵에서 진행되는 타이머와 복원, 낮 재등장, 실제 보스 탄환으로 인한 사망 초기화를 검사한다.
