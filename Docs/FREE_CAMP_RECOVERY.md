# 자유 거점·부활·사망 회수

2026-10-27 승인 범위.

## 현재 동작
- 경작은 기존 FarmGround.canFarm으로 결정한다. 농장 이름/안전 구역과 무관하다. 건물·이동 장애물·침대 자리에서는 경작하지 못한다. 씬의 땅을 선택해 Can Farm을 켜면 해당 땅에서 농사할 수 있다. 기존 마을 도로/실내의 false 설정과 사용자 씬 배치는 유지한다.
- 건축 시스템을 추가하지 않는다. 기존 집 설치와 농사 배치를 재사용한다.
- GameObject > Everything Grows > 부활 침대로 씬에 등록용 침대를 추가할 수 있다. 가까이서 우클릭해 부활 위치를 등록한다. RespawnAnchor.spawnOffset으로 침대 옆 도착 위치를 설정한다.
- 아이템 관리에 야영 침대(CampingBed), 부활 표식(RespawnToken)을 추가했다. 기존 상점 판매 목록/시작 지급품은 변경하지 않는다. NPC 관리에서 판매 목록에 넣거나 FarmItemPlacement로 배치해 사용한다.
- 야영 침대를 핫바에서 좌클릭하면 가까운 빈 땅에 간단한 침대를 설치하고 부활 위치를 지정한다. 부활 표식은 현재 서 있는 위치를 지정한다. 둘 다 성공 시 하나 소모한다. 저장 실패 시 소비/설치를 취소한다.
- 전투 사망 시 핫바를 포함한 실제 InventoryState의 전 아이템을 사망 위치의 갈색 가방에 남긴다. 별도 장비 슬롯은 아직 없다. 현재 무기는 핫바 아이템이므로 함께 남는다.
- 부활 체력은 기존 반 하트, 골드는 기존 유지. 시간이 낮으로 강제 변경되지 않는다. 마지막 HP 슬롯을 직접 떼는 GameOver 규칙은 유지한다.
- 사망 가방을 가까이에서 우클릭해 회수한다. 들어가지 못하는 물건은 가방에 남는다. 다시 죽으면 별도 가방을 만들며, 이전 가방은 지우지 않는다. 현재 자동 소멸 시간은 적용하지 않는다.
- 기본 위치는 새 게임을 처음 시작한 맵의 Player Spawn이다. 부활 위치를 지정하지 않으면 이곳으로 복귀한다. 지정 침대가 없어지면 해당 맵의 기본 스폰으로 복귀하고 등록을 해제한다. 지형 변경으로 막힌 위치는 기본 스폰 주변의 빈 위치를 찾는다.
- 기존 병원 씬/문은 삭제하지 않는다. 사망 귀환만 GameSession.RespawnAfterDeath로 전환했다.

## 저장·코드
- 저장 버전 1에 optional GameSaveData.respawn/defaultRespawn, MapSave.deathCaches/respawnAnchors를 추가한다. 기존 저장은 빈 목록/미지정으로 읽는다.
- GameSession.Respawn.cs: 위치 등록, 기본 위치, 사망 저장/이동, 저장 검증.
- FarmGame.Recovery.cs: 인벤토리 이전·회수, 가방 표시, 임시 침대 생성, 맵별 저장/복원.
- RespawnAnchor: 씬 배치/생성된 침대의 상호작용과 도착 위치.
- RespawnUseEffect: 기존 ItemUseEffect를 재사용한다. 효과 실행 안에서 저장과 소모를 함께 처리하며 공통 입력의 이중 소모 방지 규칙을 이용한다.
- 사망 저장 실패 시 아이템/가방 이전을 롤백한다. 회수 저장 실패 시 인벤토리와 가방을 되돌린다. 맵 이동 실패 시 이미 저장된 사망 가방은 유지한다.
- RecoveryFoundationCheck.Run은 임시 프로젝트와 WTF_SAVE_TEST_DIR에서만 실행한다.

## 다음 단계의 확정 방향
- 지정 농장 안전 구역 없이 자유롭게 베이스캠프를 구성한다. 건축은 추후 확장.
- 적은 플레이어만 공격한다.
- 일반 몬스터의 낮 스폰과 밤 수면은 후속 REGIONAL_MONSTERS.md에 적용됐다.
- 소멸 피해 규칙은 폐기했다. 밤에는 잠들고, 낮에 플레이어가 떠난 지역 전체가 확장 시야 밖으로 나가면 보상 없이 일반 몬스터를 정리한다. 밤에는 이탈해도 정리하지 않는다.
- 화면 밖 판정은 실제 카메라보다 넓은 영역. 보스는 시간대/화면 밖 소멸 제외.
- 고정 위치 보스는 도주/플레이어 사망 시 초기화, 처치 후 일정 시간 뒤 재등장.
- 낮 고정/방문 상인. 필드 전체 배치/상인/보스/스폰 전환은 다음 작업이다.
