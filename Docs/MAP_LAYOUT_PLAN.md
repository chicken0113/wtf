## 지역 연결

농장은 남서쪽, 던전은 북서쪽, 마을은 동쪽이라는 관계로 해석했다. 농장·마을·던전은 서로 직접 이동할 수 있는 삼각형 연결이다. 기존 마을 경유 이동을 유지하며 농장 북쪽 ↔ 던전 입구 안전 공간의 직통 통로를 추가한다.

현재는 기존 세 씬을 사용한다. 전체 지역을 한 씬으로 합치거나 농장과 던전의 내부 배치를 새로 만들지는 않는다.

## 마을

| 시설 | 위치 관계 | Town 씬의 중심 좌표 |
| --- | --- | --- |
| 길드 | 북서쪽, 농장 방향 입구 근처 | (-11, 6.5) |
| 대장간 | 북동쪽 | (10, 7) |
| 광장·분수 | 중앙 | (-1.5, 1) |
| 주택 | 남서쪽 | (-14, -3) |
| 상점 | 주택 오른쪽, 광장 남서쪽 | (-7, -3) |

길드에는 기존 안내 주민을 옮긴다. 대장장이와 주민도 해당 건물 근처로 이동한다. 상점은 기존 GeneralStore 실내와 구매·판매 기능을 유지한다. 길드·대장간의 신규 퀘스트나 강화 기능은 추가하지 않는다.

주요 길은 농장 방향 입구 → 길드 앞길 → 광장, 주택·상점 앞길 → 광장, 광장 → 북쪽 던전 입구, 광장 → 대장간으로 이어진다. 기존 문형·접촉형 출입구와 도착 ID를 유지해 저장·맵 이동과 연결한다.

## 빈 공간과 경계

- 동쪽과 남쪽 육지의 빈 곳은 잔디·소수의 나무·꽃·벤치로 가볍게 채운다.
- 동쪽 `Future building space - east`는 추후 건물 배치용 여유 공간이다. 게임 화면에 개발용 문구는 표시하지 않는다.
- 남쪽에 모래 해안과 바다를 표시하고 물 영역은 이동을 차단한다.
- 북쪽 가장자리에는 바위 경계를 두되 던전 방향 길은 열어둔다.
- 새 주요 시설의 용도나 개수는 아직 정하지 않는다.

## 편집

Town 씬의 Ground and paths / Buildings / Plaza and decorations / Residents / Travel / Touch Map Connection을 편집한다. 길드는 `TownGuild.prefab`으로 추가 배치할 수 있다. `Farm Dungeon Shortcut` 그룹은 농장·던전 직통 통로다.

사용자 초안을 적용하는 메뉴는 `Tools > Everything Grows > World > Apply approved town sketch`다. 적용 마커가 이미 있으면 마을을 다시 생성하지 않는다. 편집한 맵을 반복해서 초기화하는 용도가 아니다.

배치 변경 뒤에는 `Tools > Everything Grows > World > Validate world connections`를 실행한다. 최초 배치 검증은 도착 지점·출입구·NPC 접근점까지 길이 열려 있는지도 별도 임시 프로젝트에서 확인한다.

## 적용 결과

마을 배치와 농장↔던전 직통 통로를 본 프로젝트에 반영했다. 네 씬의 출입구 12개 연결, 마을 접근점 13곳의 통행, 상점 및 두 직통 통로의 왕복 이동과 상태 유지를 별도 프로젝트에서 검증했다.
