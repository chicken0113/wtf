# 사용자 스케치 기반 맵 배치

기준: 2026-10-21 사용자 제공 그림과 후속 요청. 큰 시설의 위치 관계는 그림을 따르고, 이후 요청에 따라 마을을 넓히고 임의 주택과 골목을 추가했다.

## 지역 연결

농장·마을·던전은 서로 직접 왕복 가능한 삼각형 연결이다. 농장 북쪽 ↔ 던전 입구의 직통 통로를 유지한다. 마을 서쪽은 농장, 북쪽은 던전 방향이며 잡화점은 별도 실내 씬으로 연결한다.

청록색 문은 E키, 주황색 통로는 몸이 닿으면 이동한다. 기존 도착 ID와 상점 설정을 유지한다. 농장과 던전 내부 배치는 이번에 변경하지 않는다.

## 넓힌 마을

Town의 경계는 40×28에서 **64×44**로 넓혔다. 면적은 약 2.5배이며 건물과 플레이어의 기본 크기는 유지한다.

| 시설 | 위치 관계 | 중심 좌표 |
| --- | --- | --- |
| 길드 | 북서쪽 | (-18, 12) |
| 대장간 | 북동쪽 | (18, 12) |
| 광장·분수 | 중앙 | (-2, 3) |
| 기존 주택 | 남서쪽 | (-22, -3) |
| 잡화점 | 주택 오른쪽 | (-13, -3) |

추가 주택 9채를 북쪽 주택가, 동쪽 골목, 남쪽 해안가에 분산했다. 기존 주택을 합쳐 주택 외관은 10채다. 집마다 열린 대문, 울타리, 짧은 진입로, 꽃밭과 나무를 배치한다. 작은 화단은 장식이며 농사용 경작지가 아니다.

길은 중앙 광장, 길드·대장간 앞, 서쪽 입구, 동쪽 주택가, 해안 산책길을 연결한다. 남쪽에는 굴곡진 해안과 바다가 있고 바다에는 진입할 수 없다. 북쪽은 나무 경계 사이로 던전 길이 열린다.

기존 주민 3명과 잡화점의 대화·거래 기능은 유지한다. 추가 주택은 현재 외관 배치용이다. 주택 실내·새 주민·퀘스트·시설 기능을 추가한 것은 아니다.

## 씬에서 편집

`Assets/Scenes/Town.unity`에서 `EditableMap` 아래 그룹을 편집한다.

- `Ground and paths`: 잔디·길·해안 타일
- `Buildings`: 길드·대장간·기존 주택·잡화점
- `Residential neighborhoods`: 추가 주택 9개의 개별 마당 그룹
- `Plaza and decorations`: 광장·분수·벤치·가로등·나무·해안
- `Residents`: 기존 주민
- `Travel` 등 출입구 그룹: 연결 ID를 유지한 채 위치 변경 가능

추가 주택은 `TownHouse.prefab` 인스턴스다. `House yard 01` 같은 그룹을 통째로 옮기거나 펼쳐 건물·울타리·화단을 개별 변경할 수 있다. 건물의 `MapObstacle`은 그림과 별개인 발밑 충돌 영역이다.

`Tools > Everything Grows > World > Apply spacious town layout`은 이번 확장을 한 번 적용하는 메뉴다. 적용 마커가 있으면 다시 생성하지 않으므로 이후 수동 편집을 덮어쓰지 않는다. 이전 스케치 적용 메뉴도 이전 마커를 유지한다.

배치를 변경한 뒤 `Tools > Everything Grows > World > Validate world connections`로 연결·도착 위치를 검사한다. 이 메뉴는 전체 길의 통행 가능성까지 보장하지 않는다.

## 검증과 미리보기

별도 프로젝트에서 네 씬의 출입구 12개 연결과 도착·출입구·NPC·추가 주택 대문까지 총 22곳의 이동 경로 검사가 통과했다. 실제 Play에서 상점·주민 대화, 문형·접촉형 왕복, 농장↔던전 직통 이동, 작물·소지품·골드와 자동 저장 상태 유지를 확인했다. 화면에서 북쪽 주택과 나무가 바닥 뒤에 가려지는 문제도 수정하고 실제 Town 씬에 적용했다.
