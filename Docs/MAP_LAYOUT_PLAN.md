# 마을 배치 기준

## 현재 기준: 펠리컨 타운

2026-10-21 사용자가 이전 확장안의 길이 난잡하다고 지적하고 스타듀밸리 마을을 그대로 기준으로 재구성하도록 요청했다. 이전 손그림의 시설 방향과 임의 주택가 배치를 대신한다.

- [참고한 펠리컨 타운 지도](https://images.squarespace-cdn.com/content/v1/64bf8ed4bcdd7401d84ca74a/76d01239-2dee-4fbf-ac61-f25fdc1516e6/1200px-Pelican_Town.png)
- [시설·지역 연결 참고](https://stardewvalleywiki.com/Pelican_Town)

그림의 도로·건물·강·다리 위치를 프로젝트 좌표로 옮긴 배치용 재현이다. 원작의 건물·타일 그래픽을 가져오지 않았으며 기존 프로젝트의 집과 지도용 임시 도형으로 표현한다. 타일 단위 원본 데이터나 원작과 동일한 외관을 구현한 것은 아니다.

## 지형과 동선

Town은 64×60 크기다.

- 북쪽: 회관 외관, 공원, 분수, 놀이터와 두 계단 통로
- 중앙 서쪽: 잡화점과 진료소 외관, 돌바닥 광장과 남북 중심길
- 광장 동쪽: 주점 외관과 강변 주택·트레일러
- 남서쪽: 주택 두 채와 연결된 주택가 길
- 남동쪽 강 건너: 대장간·박물관 외관
- 북동쪽 강 건너: 큰 상점 외관
- 동쪽에서 남쪽으로 이어지는 강, 동서 연결 다리 두 개와 남쪽 세로 다리

회관은 기존 길드 외관을 재사용한다. 신규 외관은 시설 위치를 표현하기 위한 것이며 새 기능·거래·주민·실내를 추가하지 않는다. 기존 잡화점만 GeneralStore 실내 및 구매·판매와 연결된다.

서쪽의 문형·접촉형 출구는 농장으로, 북쪽 두 출구는 던전으로 이어진다. 남쪽 다리는 현재 풍경이며 별도 해변 씬은 없다. 농장↔던전 직통 통로도 유지한다.

## Scene 편집

`Assets/Scenes/Town.unity`의 `EditableMap` 아래에서 편집한다.

- `Ground and paths`: 잔디·돌길·흙길·강·다리 바닥
- `Buildings`: 기존 회관·잡화점·대장간·남서쪽 주택
- `Town districts`: 나머지 시설과 주택 외관
- `Plaza and decorations / River and three bridges`: 강 충돌과 다리 난간
- `Plaza and decorations / North park and playground`: 공원·분수·놀이터·계단
- `Plaza and decorations / Gardens and trees`: 수목·울타리·화단
- `Residents`: 기존 주민 3명
- `Travel` 등 이동 그룹: 출입구·도착 ID 유지

오브젝트와 건물은 Scene에서 직접 이동·삭제·교체 가능하다. 추가 건물은 기존 TownHouse 프리팹 인스턴스이며 크기와 색을 달리해 구분한다. MapObstacle은 이동을 막는 영역이다.

`Tools > Everything Grows > World > Apply Pelican Town reference layout`은 이번 배치를 한 번 적용하는 메뉴다. 적용 마커가 있으면 재생성하지 않아 이후 수동 편집을 덮어쓰지 않는다. 이전 확장 메뉴도 이전 마커를 유지하므로 새 배치를 되돌리지 않는다.

## 검증 결과

별도 Unity 프로젝트에서 출입구 12개 연결, 접근점 25곳의 경로, 다리 밖 강 이동 차단을 확인했다. 실제 Play에서 네 씬의 왕복, NPC 대화·상점 거래, 농장↔던전 직통 이동과 작물·소지품·골드·자동 저장 상태 유지가 통과했다. 이전 마을 입장 위치가 새 공원 경계와 겹치는 저장도 정상 복원되는지 확인했다. 새 지형에 막힌 저장 위치만 현재 맵 시작점으로 옮기고, 유효한 저장 위치와 골드는 유지한다.
