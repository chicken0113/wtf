# 야간 상인

2026-10-27 적용.

## 공통 시간 규칙
- 상점 사용이 켜진 NPC는 고정 위치/방문 상인 모두 **Night 구간에만 등장·거래**한다. 낮·해질녘·새벽에는 모델/콜라이더/상호작용을 숨긴다. 기존 실내 상인도 동일하다.
- 기존 ShopNpc.daytimeOnly는 비상점 NPC의 기존 주간 대화 규칙에만 사용한다. 상인은 이 옛 필드와 관계없이 공통 야간 일정을 따른다. 길드 등 비상점 NPC의 별도 대화 가능 시간은 유지한다.
- 거래 도중 시간대를 직접 넘기거나 향후 시간이 계속 흐르는 모드에서 새벽이 되면 상점과 해당 인벤토리 표시를 닫는다. 현재 싱글플레이 메뉴 중 시간 정지 규칙은 바꾸지 않는다.
- 상인 공격/죽음/부활 기능을 추가하지 않는다. 몬스터는 기존처럼 플레이어만 공격한다.

## NPC 관리 설정
Tools > Everything Grows > NPC 관리에서 해당 씬과 프로필을 선택한다.
- **상점 사용**을 켠다. 기존 판매 품목·구매가·판매가를 그대로 쓴다.
- **확률 방문 상인**을 끄면 배치된 고정 위치에서 밤마다 등장한다.
- 켜면 **밤마다 방문 확률(%)**과 **방문 후보 위치**를 지정한다. 확률 0%/100%도 지원한다.
- **후보 위치 추가**는 같은 씬에 빈 오브젝트를 만들고 후보 목록에 연결한다. Scene에서 원하는 빈 땅으로 이동한 뒤 기존 ‘이 씬 저장’을 누른다.
- 후보 위치는 같은 씬에 있어야 하며 NPC 몸체의 자식으로 두지 않는다. 방문 프로필 하나에 캐릭터 몸체 하나를 연결한다. 실제 캐릭터는 기존 Merchant 프리팹과 Npc Id를 사용한다.
- 후보가 월드 밖/장애물·집 내부이면 추첨 후보에서 제외한다. 유효한 후보가 하나도 없으면 그 밤은 방문하지 않는다.
- 떠날 때 원래 배치 위치로 돌아가 숨기며 다음 방문은 다시 후보 중에서 정한다. 후보 위치/확률을 편집해도 이미 결정된 같은 밤 결과와 위치는 바꾸지 않는다.

## 방문 결과·저장
- 월드의 저장된 seed와 씬·NPC 프로필 ID·밤 식별자를 사용하는 고정 해시로 방문과 후보 위치를 정한다. 밤 늦게 처음 들어간 맵도 동일 규칙을 쓴다. Unity 전역 Random 상태를 소비하지 않는다.
- 방문뿐 아니라 **불참 결과도** 저장한다. 맵 이동·이어하기로 다시 추첨하지 않는다. 다음 밤에는 새 결과를 계산한다. 같은 위치가 연속으로 선택될 수 있다.
- 각 씬/프로필에 최신 밤 결과 하나만 보관해 기록이 밤 수만큼 계속 늘어나지 않는다.
- 밤 식별자는 날짜/플레이어 UI 진행 시스템이 아니라 결과를 구분하는 내부 순환 번호다. 기존 시간 주기가 한 바퀴 돌 때 증가하며 플레이어 저장에 함께 보관한다.
- 버전 1에 optional GameSaveData.merchantSeed/nightVisits, PlayerSave.cycleNumber를 추가한다. 이전 저장은 번호 0으로 읽고 seed를 준비하며, 필요하면 최초 방문 결과와 함께 저장한다.
- 방문 결과가 새로 결정된 밤에는 저장한다. 맵 도착 중에는 기존 도착 검증 뒤 저장을 재사용하고, 저장 실패는 기존 재시도 안내를 따른다.

## 예시
- 숲에 기존 Merchant 모델로 **밤의 행상인**을 한 명 추가했다.
- 방문 확률 35%, 후보 위치 두 곳. 같은 밤에는 재입장해도 등장 여부와 위치가 유지된다.
- 기존 아이템인 야영 침대/부활 표식/파스닙 씨앗을 판매한다. 확률과 가격은 NPC 관리에서 수정한다.
- 기존 고정 상인들은 개별 씬 재배치 없이 시간 규칙만 야간으로 전환한다. 예시 배치는 명시적 일회 작성이며 에디터 시작 때 재생성하지 않는다.

## 코드
- NpcManager.UpdateAvailability: 프로필 일정·방문 결과에 따라 몸체 위치/표시/거래 창을 갱신한다.
- GameSession.Merchants: seed/해시/밤별 캐시/저장 검증. GameSession.Bind가 복원 후 현재 씬 상인의 상태를 다시 적용한다.
- DayNightCycle.ShopsOpen/CycleNumber: 엄격한 밤 구간과 순환 식별자.
- NpcManagerWindow: 기존 씬 프로필 도구에 확률·후보 위치 설정을 추가했다. Undo/명시적 씬 저장/Play 수정 차단을 재사용한다.
- NightMerchantCheck.Run: 임시 프로젝트와 WTF_SAVE_TEST_DIR에서 낮/해질녘/밤/새벽, 거래/강제 닫기, 고정 실내 상인, 방문/불참 유지, 맵 이동·실제 디스크 재로드, 다음 밤 새 추첨, 잘못된 설정 진단을 확인한다.
