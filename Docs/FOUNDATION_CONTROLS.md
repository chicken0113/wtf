# 기본 조작과 메뉴 동작

현재 싱글플레이 시제품 기준입니다. 최종 맵 배치·조작 안내 화면과 설정 메뉴는 데모 일정에 따라 별도로 다듬습니다.

기능별 코드 수정 위치·호출 흐름·검증 방법은 [코드 수정 안내](CODE_MAP.md)를 참고합니다.

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 이동 방향과 독립적으로 조준·사용·식재 위치 지정 |
| 좌클릭 | 도구 사용·무기 공격·집 설치. 괭이는 경작 또는 식재물 제거(반환 없음) |
| 우클릭(월드) | 가리킨 NPC 대화·상점·의뢰·문·계단 / 바닥 물건 줍기·심기·작물·집 수확 |
| E / F | 할당 없음 |
| 주황색 통로 접촉 | 농장·마을·던전 사이를 E 없이 자동 이동 |
| 우클릭(UI) | 하트 수확·인벤토리 슬롯 떼기·상점 물품 한 개 판매; 대화/상점 창 밖은 닫기 |
| 1~9 / 마우스 휠 | 핫바 선택·장착 |
| Tab | 보관 칸·핫바를 함께 열기/닫기; 골드 확인 |
| M | 지도 열기·닫기 |
| Esc | 열린 인벤토리·상점·대화·지도 닫기 |
| Q | 선택한 아이템 하나 떨어뜨리기 |
| Space / Shift | 이동 중에는 이동 방향으로 회피; 멈춰 있으면 조준 방향 |

기존 특수 상호작용: 하트를 마우스로 가리키고 우클릭하면 하트 한 칸을 수확합니다. 인벤토리 슬롯을 우클릭하면 슬롯을 뜯고 R로 복구합니다. 상점이 열린 동안 슬롯 우클릭은 물품 한 개 판매입니다. 바닥 아이템은 우클릭으로 줍습니다. 성장 중인 대상은 회수할 수 없고, 다 자란 뒤 우클릭으로 수확하거나 괭이 좌클릭으로 제거합니다. 괭이 제거는 물건을 반환하지 않고 경작지를 남깁니다. 심어진 대상 제거는 괭이로 통일합니다. 도구 사용은 좌클릭입니다.

## 이동·조준·회피

- 마우스 방향으로 몸과 무기가 향하며 이동해도 조준 방향을 강제로 바꾸지 않습니다. UI 위에서는 마지막 조준 방향을 유지합니다.
- 대각선 이동은 가로·세로와 속도가 같고, A+D / W+S는 서로 상쇄됩니다.
- 기본 이동 속도 4.5, 회피 속도 11·지속 0.22초(장애물 없으면 약 2.42칸), 시작 간격 0.65초입니다. 회피 중 무적이며 벽을 통과하지 않습니다.
- 재사용 대기 마지막 0.12초 안에 누른 회피는 준비되면 실행됩니다. 오래 전에 누른 입력이 뒤늦게 실행되지는 않습니다.
- `Tools > Everything Grows > Player controls`에서 이동 속도·회피 속도/지속/재사용 시간/입력 여유를 수정합니다. 변경한 설정은 다음 Play부터 사용합니다.

## 액션 반응

- 근접 공격은 누른 순간 판정하고, 공격 방향의 부채꼴 궤적과 손에 든 무기의 휘두르기를 표시합니다. 공격 간격과 피해량은 기존 무기 데이터를 유지합니다.
- 원거리 공격은 발사 효과·무기 반동을 표시합니다. 기본 플레이어 탄속은 18이며 최대 사거리는 기존 무기 데이터대로 유지합니다. 탄환은 이동 구간을 검사하므로 빠르더라도 벽이나 가까운 적을 건너뛰지 않습니다.
- 적이 맞으면 짧은 색 변화·파편·경직이 생기고 공격 준비가 취소됩니다. 살아남은 일반 적의 밀려남과 훈련 표적의 보상 없음은 유지합니다.
- 적의 공격 준비는 조준한 방향의 선으로 표시합니다. 적 탄환은 발사 시 정한 방향으로 진행하며 플레이어를 따라 휘지 않습니다.
- 회피 중 캐릭터가 회전하고 잔상을 남깁니다. 무기는 잠시 숨겨져 몸 주위를 돌지 않습니다.
- 괭이·물뿌리개·낫은 좌클릭을 누른 채 다른 칸으로 옮겨 연속 사용합니다. 같은 칸은 누른 동안 재사용하지 않으며 기본 사용 간격은 0.1초입니다. 집 설치·하트 복구는 매번 새 클릭이 필요합니다.
- `Player controls`의 `Projectile Speed`, `Weapon Recoil`, `Camera Shake`, `Tool Drag Interval`로 탄속·반동·화면 흔들림·농기구 연속 사용 간격을 조절합니다. `Camera Shake`를 0으로 하면 화면이 흔들리지 않습니다. 흔들림은 마우스의 실제 조준 지점에 영향을 주지 않습니다.
- 현재는 기존 그림을 이용한 간단한 동작·시각 효과입니다. 효과음과 완성된 캐릭터 애니메이션은 별도 작업입니다.

## 우클릭 대상

- UI를 먼저 처리합니다. 거래 중에는 상점과 인벤토리 패널 모두 창 안으로 취급합니다.
- 월드에서는 가리킨 NPC → 가리킨 문/계단 → 바닥 아이템 → 집/작물 수확 → 심기 순서입니다.
- 가까운 NPC가 있더라도 가리키지 않았다면 농사 클릭을 가로채지 않습니다.
- 문/계단 앞에서 발판을 가리키고 우클릭합니다. 막힌 문/계단이나 사거리 밖의 NPC를 클릭해도 뒤의 농사 행동으로 넘어가지 않습니다.
- 집 몸체를 우클릭하면 집을 수확하고, 문 발판을 우클릭하면 입장합니다.
- 성장 중인 대상은 회수할 수 없습니다. 괭이 제거 규칙은 유지합니다.
- 하트는 UI 우클릭의 명시적 예외이며 한 칸씩 수확합니다.
- 메뉴를 여닫은 클릭은 판매·슬롯 떼기·월드 행동에 재사용하지 않습니다.

## 메뉴와 입력 충돌 방지

- 인벤토리·상점·대화창·지도가 열리면 싱글플레이의 시간·성장·전투가 멈춥니다. 닫으면 이어집니다.
- 메뉴 뒤의 도구·공격·심기·수확·하트 수확·문 이동이 실행되지 않습니다.
- Esc 또는 대화·상점·길드 창 밖 우클릭으로 닫습니다. 닫는 클릭은 뒤의 밭·문·핫바를 작동시키지 않습니다.
- Tab과 M으로 창을 전환할 때도 해당 입력은 메뉴가 처리합니다.
- 상점에서는 물품을 구매하고 인벤토리 물품을 우클릭해 판매합니다. 대화만 하는 주민은 구매·판매 기능을 열지 않습니다.
- 멀티플레이는 이번 데모 범위 밖입니다. 현재 규칙은 싱글플레이 전용입니다.

## 저장

맵 이동 전후 자동 저장하며, 다시 실행하면 마지막 저장된 맵·상태를 복원합니다. 인벤토리 창을 닫거나 게임을 종료하는 것만으로 새 자동 저장을 만들지는 않습니다. 집에서 시간 보내기 저장은 연결 함수만 있으며 실제 행동은 아직 없습니다.

## 인벤토리 이동과 칸 수

Tab 창 위쪽은 보관 칸, 아래쪽은 핫바다. 아이템을 좌클릭으로 끌어 빈칸에 놓으면 이동하고, 다른 아이템 위에 놓으면 두 칸을 교환한다. 창 밖에 놓으면 드래그한 묶음을 플레이어 발밑에 버린다. Esc나 X로 닫으면 원래 자리에 남는다. 창을 닫으면 핫바만 보이며 숫자/휠은 핫바를 선택한다. 보관 칸의 아이템은 핫바로 옮겨 사용한다. 우클릭 판매/슬롯 떼기는 기존대로다.

`Assets/Resources/StartingInventory.asset`의 **Hotbar Slots**와 **Storage Slots**를 Unity Inspector에서 따로 설정한다. 변경은 다음 Play 시작 시 적용되며 기본 4+1칸으로 기존 총 5칸을 유지했다. 성장한 보관 아이템의 추가 용량은 보관 칸에 붙는다. 저장에는 빈칸과 아이템 위치가 유지되며 예전 저장도 읽는다. 칸 수를 줄여 넘치는 물건은 바닥에 떨어진다.

### 묶음과 아이템 설명

- 같은 종류의 묶을 수 있는 아이템 위에 놓으면 수량을 합친다.
- Shift+좌클릭 드래그는 절반을 옮긴다. 홀수면 큰 쪽(예: 5개 중 3개)이다. 분할 묶음은 빈칸이나 같은 아이템에만 놓을 수 있고, 다른 물건 위에 놓으면 취소한다.
- 창 밖 버리기도 드래그한 수량만 적용된다. 창 안 빈 공간이나 상점 패널에 놓으면 버리지 않는다. 바닥에 버린 아이템은 기존 줍기로 회수할 수 있다.
- 인벤토리와 핫바의 아이템에 마우스를 올리면 이름·수량·간단한 용도를 표시한다. 각 PlantDefinition 에셋의 **Description**으로 설명을 수정하고, 비워 두면 기본 용도를 표시한다.
