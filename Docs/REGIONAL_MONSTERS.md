# 지역 몬스터 스폰·수면

2026-10-27 확정 규칙 및 적용.

## Unity 설정
1. Tools > Everything Grows > 몬스터 관리에서 몬스터 종류를 선택한다.
2. **출현 가능한 지역**에 SpawnRegion 에셋을 여러 개 연결한다. 빈 목록이면 자동 스폰되지 않는다.
3. 같은 창의 **지역 설정 열기**에서 지역을 추가/선택하고 대상 씬, 범위, 스폰 간격(초), 일반 몬스터 최대 수, 카메라 여유, 플레이어 주변 생성 제외 거리를 설정한다.
4. 맵 전체 범위 사용을 끄면 한 씬을 여러 직사각형 지역으로 나눌 수 있다. 활성 씬에서는 선택 지역 경계를 Scene 뷰에 표시한다. 겹치는 지역은 각자 스폰하므로 필요할 때만 겹친다.
5. 변경은 Undo와 에셋 자동 저장을 지원한다. Play 중 수정은 차단한다. 관리창은 사용자 씬을 자동 생성·저장·닫지 않는다.
6. 보스는 MonsterType의 **보스**를 켜고 기존 EnemyPlacement로 맵에 고정 배치한다. 지역 목록에 연결해도 보스를 무작위 생성하지 않는다.

기본 연결: FirstGarden(시작 야영지), FarmTownPassage(통로), DungeonEntrance(중앙 필드), ForestClearing(숲). 우선 맵 전체를 지역으로 쓰며 8초 간격/최대 6마리, 시야 여유 3, 생성 제외 거리 3으로 두 종류를 연결했다. 초기 조절값이며 난이도 확정이 아니다. 마을·실내·훈련장·기존 탑의 배치/진행은 변경하지 않는다. 기존 씬과 사용자 배치는 그대로 두고 Resources/SpawnRegions에서 설정한다.

## 시간과 지역 수명
- 지역이 연결된 필드의 예전 일반 EnemyPlacement 표시는 사용하지 않는다. 일반 몬스터는 종류의 지역 설정을 통해 생성하므로 첫 야간 진입에도 생성되지 않는다. 보스·훈련 표적의 고정 배치는 유지한다.
- 밝은 낮(Daylight)에만 플레이어가 안에 있는 지역에서 자동 스폰한다. 현재 적 수가 최대 이상이면 추가 생성하지 않는다. 지역 첫 진입/정리 후 재진입은 첫 생성 시도가 즉시 가능하다.
- 해질녘/밤/새벽에는 스폰과 지역 정리를 모두 멈추고 기존 몬스터는 잠든다. 수면 중에도 모델/피격은 유지하며 Zzz를 표시한다. 이동·공격·개체 밀어내기는 멈춘다.
- 잠든 몬스터를 공격하면 해당 개체만 즉시 깨어나 공격 대기를 해제하고 플레이어에게 반격한다. 공격 예고와 피격 경직은 기존 전투 규칙을 따른다. 해당 밤에는 깨어 있는 상태를 유지한다. 다음 낮에 모두 깨어나며, 다음 밤에는 다시 잠든다.
- 낮에 플레이어가 지역 밖이고 지역 전체가 여유를 포함한 카메라 사각형과 겹치지 않을 때 일반 몬스터를 정리한다. 스폰된 지역 기준으로 추적하므로 그 지역 출신이 플레이어를 쫓아 밖으로 나온 경우도 정리 대상이다.
- 지역을 벗어났어도 화면과 겹치면 유지한다. 벽/지형에 가려지는지는 판정에 사용하지 않는다.
- 지역 정리는 전투 처치가 아니다. 아이템·골드·처치 수·길드 진행을 지급하지 않는다.
- 보스는 지역 이탈 정리에서 제외한다. 보스도 밤에 잠들며 공격받으면 깨어난다. 보스의 패턴/이탈 초기화/시간 재등장은 별도 후속 작업이다.
- 밤에 다른 맵으로 이동하면 위치·체력·출신 지역·밤에 공격받아 깨어난 상태를 보관한다. 밤에 돌아오면 복원한다.
- 다른 씬은 현재 단일 씬 이동 구조에서 화면 밖으로 본다. 낮에 다른 씬에 도착하거나 낮이 시작되면 저장된 다른 씬의 일반 지역 몬스터를 정리하고 보스는 보존한다.
- 직접 처치한 몬스터는 낮/밤과 관계없이 기존 보상을 준다. 훈련 표적은 지역 스폰·수면·정리에서 제외한다.

## 안전구역과 저장
- 지역 설정이 연결된 필드는 기존 SafeBounds 면역, 적 이동 금지, 탄환 차단과 안전 마커를 사용하지 않는다. 몬스터의 공격 대상은 기존 플레이어 하나다. 작물/설치물/NPC 공격을 추가하지 않는다.
- 기존 탑과 훈련장 등 지역이 연결되지 않은 씬은 기존 배치 방식과 스케줄을 유지한다.
- 버전 1에 optional MapSave.regionalCombatSaved/regionalEnemies를 추가한다. 지역 저장은 개체 ID·종류 ID·출신 지역·위치·귀환 위치·표시 크기·HP·야간 각성 여부를 보관한다. 일반 적 사망은 개체 목록에서 제외하고 보스 사망 상태는 보존한다.
- 이전 층 저장이 지역 기반 필드로 처음 전환되는 경우 한 번 초기 지역 개체군으로 시작한다. 기존 층 영구 클리어 설정은 지역 스폰을 막지 않는다.
- MonsterType.saveId와 SpawnRegion.id는 에셋 생성 시 고유 ID를 부여한다. 에셋 이름 변경은 ID를 바꾸지 않는다. 일반 복제 대신 관리창의 생성/복제를 사용한다. 잘못된 참조·중복 ID·잘못된 범위/수치는 초기 설정 검사에서 안내한다.

## 담당 코드
- SpawnRegion: 지역 설정과 여유 카메라 범위 계산.
- RegionalSpawnSystem: 지역별 타이머/종류 선택/생성 위치/이탈 정리.
- EnemyCombatSystem.Regions: 개체 수면·지역 정리·개체군 저장/복원. 기존 EnemyCombatSystem은 이동/공격/피격을 계속 담당한다.
- GameSession.Regions: 불러오지 않은 맵의 낮 정리와 저장 개체 검증.
- SpawnRegionWindow: 지역 설정 UI. 몬스터 관리의 종류 편집은 기존 MonsterRewardsWindow.
- RegionalMonstersCheck.Run: 격리된 프로젝트/저장에서만 실제 맵 왕복과 낮밤 전환 검사.
