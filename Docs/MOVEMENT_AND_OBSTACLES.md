# 이동과 장애물 배치

## 씬에서 추가하기

- 벽·바위 등 기존 오브젝트에 `Map Obstacle` 컴포넌트를 추가합니다. 또는 `Assets/Prefabs/Map/MapObstacle.prefab`을 배치해 보이지 않는 충돌 영역을 만듭니다.
- Hierarchy의 `GameObject > Everything Grows > Map Obstacle`로도 추가할 수 있습니다.
- `Size`와 `Offset`은 로컬 좌표입니다. 선택한 상태에서 Scene의 박스 핸들을 끌어 조절할 수 있습니다. Scene의 Gizmos를 켜면 주황색 영역이 표시됩니다.
- `Blocks Movement`: 플레이어·몬스터 이동 차단.
- `Blocks Projectiles`: 아군·적 탄환 차단. 근접 공격과 몬스터 공격 시야도 이 설정을 사용합니다.
- 둘은 따로 설정할 수 있습니다. 컴포넌트나 오브젝트를 끄면 차단하지 않습니다.
- 이 컴포넌트는 충돌 영역만 만듭니다. 외형은 SpriteRenderer 등으로 직접 추가합니다. 일반 Collider2D만 추가한 오브젝트는 이 이동 시스템에서 차단하지 않습니다.

충돌은 **월드 축에 맞춘 사각형**을 사용합니다. 회전한 오브젝트는 주황색으로 표시되는 바깥 사각형 전체가 막힙니다. 복잡한 외형은 여러 작은 장애물로 나누어 배치하세요. 컴포넌트를 몬스터나 플레이어에 붙이지 마세요.

기존 집은 `FarmBuilding`의 바닥 영역을 자동으로 사용합니다. 집 수확 시 해당 충돌도 사라지며 다시 설치하면 복원됩니다. 별도 MapObstacle을 중복 추가할 필요가 없습니다.

## 이동과 전투

- 플레이어는 반경만큼 여유가 있는 사각형으로 충돌합니다. FarmGame의 `Player Radius`로 반 크기를 설정합니다. FarmGame을 선택하면 청록색 판정이 보입니다.
- 이동 경로 전체를 검사하므로 빠른 이동과 구르기도 벽을 넘지 않습니다. 대각선으로 벽에 닿으면 가능한 축으로 미끄러집니다.
- 몬스터는 0.5칸 간격의 경로를 탐색해 장애물을 우회합니다. 모서리를 대각선으로 자르지 않으며 서로 겹치면 밀어냅니다. OpenFieldCombat의 `Enemy Radius`로 판정을 조절합니다.
- 경로 탐색은 최대 8,000개 노드를 검사하고, 막힌 경로는 약 0.6초마다 재탐색합니다. 통과할 길이 없으면 접근 가능한 위치까지만 이동합니다. 몬스터 크기보다 좁은 통로는 통과하지 않습니다.
- 탄환은 프레임 사이 이동 경로를 검사하고 가장 먼저 만나는 벽이나 대상에 맞습니다. 벽 너머로 근접 공격도 전달되지 않습니다.
- 저장 복원·맵 도착·사망 귀환은 순간 배치합니다. 도착 지점과 스폰 지점은 장애물 밖에 배치하세요.

현재 씬의 배치는 변경하지 않았습니다. 기존 낮밤·안전구역 동작을 유지하며, 별도 던전과 진행 규칙은 아직 구현하지 않았습니다.

## 검증

사용자 씬과 저장 파일을 건드리지 않는 별도 프로젝트 복사본에서 `MovementCollisionCheck.Run`으로 이동·구르기·벽 타기·우회·몬스터 분리·양쪽 탄환 차단·탄환 통과 설정·가까운 대상 우선 피격을 검증합니다.
