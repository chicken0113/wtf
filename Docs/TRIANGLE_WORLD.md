# 삼각형 월드 기본 배치

건물 내부 확장 이후에는 아래 야외·상점 8개 씬에 집·길드·대장간 내부 3개 씬이 추가되어 총 11개 씬을 사용한다. 최신 실내 연결과 NPC 기능은 [BUILDING_INTERIORS.md](BUILDING_INTERIORS.md)를 참고한다.

## 연결

```text
                   던전 내부
                      │
숲·버려진 공터 ─ 던전 입구 필드 ─ 훈련장
                   /      \
                 농장     마을 ─ 잡화점 실내
                   \      /
                    연결 통로
```

실제 연결: 농장↔통로↔마을, 농장↔입구 필드↔마을, 입구 필드↔던전/숲/훈련장.

| 씬 | 크기 | 역할 |
| --- | --- | --- |
| FirstGarden | 기존 유지 | 집·밭·상인 |
| Town | 기존 64×60 유지 | 길드·대장간·광장·상점 외관 |
| FarmTownPassage | 24×14 | 짧은 농장↔마을 연결 |
| DungeonEntrance | 40×28 | 삼각형 동선의 위쪽, 동굴 입구 |
| ForestClearing | 28×24 | 숲·버려진 물건, 기존 돌·구름 4개 배치 |
| TrainingGround | 26×22 | 표적 3개와 기존 검·활 획득물 |
| CombatTest | 기존 유지 | 기존 근접·원거리 적 전투 공간 |
| GeneralStore | 기존 유지 | 기존 잡화점 구매·판매 |

새 맵은 게임 실행 중 생성하지 않는다. 모두 Scene에서 `EditableMap` 아래 바닥, 길, 장식, 아이템, 표적, Travel을 편집한다. 현재 그림은 동선 참고이며 픽셀아트 지도와 같은 완성 그래픽을 구현한 것은 아니다. 프로젝트에 있는 그림과 임시 블록을 사용한다.

## 이동

- 모든 야외 연결은 접촉식 주황 통로. 동굴 입장도 자동이다.
- 잡화점 입장·퇴장은 기존 파란 E 문.
- 도착 지점은 출구에서 떨어뜨려 즉시 반대 맵으로 되돌아가지 않도록 한다.
- 기존 도착 ID는 삭제하지 않는다. 기존 저장 맵·인벤토리·골드는 유지한다.
- 마을 던전 방향 출입구를 길드 북쪽 접근로로 옮긴다. 길드와 다른 건물의 위치·지붕 표식은 유지한다.

## 기존 기능 재사용

- 숲: FarmItemPlacement로 기존 아이템 배치. 별도 채집 기능 없음. 줍고 난 상태는 기존 맵 저장으로 유지.
- 훈련장: EnemyPlacement의 Training Dummy를 켠 표적. 기존 근접 공격·투사체 충돌·체력 표시·피격 처리를 사용한다. 이동과 공격을 하지 않는다. 파괴 후 3초 뒤 회복하고 처치 수·아이템 보상을 주지 않는다.
- 상점과 대장간의 거래 시스템은 추가하지 않는다. 기존 NPC 매니저를 유지한다.
- 집·길드·대장간 실내, 길드 의뢰는 후속 작업.

## 편집 도구

`Tools > Everything Grows > World > Apply triangle world layout`은 최초 배치 도구다. 적용 표시가 있는 기존 씬과 이미 생성한 새 씬을 다시 만들지 않는다. 수동 편집 후 초기화용으로 사용하지 않는다.

`Validate world connections`로 8개 씬의 연결, 도착 지점, 이동 충돌, NPC 참조를 확인한다. 실제 왕복·획득·표적·저장 검사는 별도 프로젝트의 `TriangleWorldCheck.Run`을 사용한다.

## 별도 프로젝트 검증

8개 씬·출입구 16개의 목적지와 도착 지점, 시작점에서 아이템·출입구·도착 지점까지의 통행 검사가 통과했다. 실제 Play에서 16방향 이동, 잡화점 E 출입, 숲 아이템 획득, 훈련 표적 근접·원거리 피격 및 회복, 보상 없음, 플레이어 피해 없음, 인벤토리·골드 유지와 맵 전환 자동 저장을 확인했다. 새 필드·숲·훈련장 Play 렌더링을 확인했다.
