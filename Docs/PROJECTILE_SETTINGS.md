# 무기·몬스터별 탄환 설정

2026-10-27 적용.

## 도구
- Tools > Everything Grows > 아이템 관리에서 Weapon + Ranged인 아이템을 선택하면 **탄환 사거리(칸), 탄속(칸/초), 최대 유지 시간(초)**을 각각 설정한다.
- Tools > Everything Grows > 몬스터 관리의 **원거리 탄환**에서도 같은 세 수치를 몬스터 종류별로 설정한다. 몬스터의 **공격 시작 거리**는 별도다. 근접 행동에서는 탄환 수치를 사용하지 않는다.
- 두 창에 실제 최대 이동 거리와 유지 시간을 표시한다. 기존 Undo/에셋 자동 저장/Play 수정 차단을 그대로 사용한다.
- 실제 이동 거리 = min(사거리, 탄속 × 최대 유지 시간). 실제 유지 시간 = min(최대 유지 시간, 사거리 ÷ 탄속). 거리/시간 중 먼저 한도에 도달하면 제거한다. 벽이나 대상에 맞으면 그 전에 제거한다.
- 고정 탄속의 직선 탄환이므로 발사할 때 두 제한으로 유효 수명을 계산하고 기존 탄환 시스템에서 처리한다. 발사 중 설정 변경은 이미 날아가는 탄환을 바꾸지 않는다.

## 기본값 유지
| 대상 | 사거리 | 탄속 | 최대 유지 시간 | 실제 거리 / 시간 |
|---|---:|---:|---:|---|
| 활 | 8 | 18 | 1 | 8 / 약 0.444초 |
| 총 | 10 | 18 | 1 | 10 / 약 0.556초 |
| 원거리 몬스터 | 11.25 | 4.5 | 2.5 | 11.25 / 2.5초 |

- PlantDefinition.attackRange는 기존 직렬화 필드를 유지하며 원거리 무기에서는 탄환 사거리, 근접 무기에서는 공격 사거리로 쓴다. projectileSpeed/projectileLifetime을 추가했다.
- MonsterType은 기존 projectileSpeed/projectileLifetime을 재사용하고 projectileRange를 추가했다.
- PlayerControls.projectileSpeed는 과거 직렬화 값 보존을 위해 숨겨서 남긴다. 이제 탄속은 아이템에서 지정한다.
- 0 이하·NaN/Infinity 값은 기존 설정 검사에서 오류로 안내한다. 매우 빠르고 짧은 거리의 탄환도 최소 수명 보정 때문에 더 멀리 가지 않도록 처리한다.
- 저장 데이터/씬/전투 피해·보상 규칙은 변경하지 않는다.

## 코드
ProjectileSettings.Duration/Distance가 실행과 도구의 계산을 공유한다. 플레이어 발사는 OpenFieldCombat.Attack, 몬스터 발사는 EnemyCombatSystem.TickEnemy에서 각 데이터로 계산한 수명을 전달한다. ProjectileConfigurationCheck.Run은 임시 Unity 프로젝트에서 기본 사거리 보존, 무기별 속도, 거리/시간 만료, 빠른 단거리 탄환, 실제 몬스터 발사와 잘못된 값 검사를 수행한다.
