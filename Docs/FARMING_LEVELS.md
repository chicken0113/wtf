# 농사 레벨과 심기 해금

## Unity 설정

- `Assets/Resources/FarmingLevels.asset` → Experience To Next Level: 원소 0은 1→2, 원소 1은 2→3에 필요한 경험치. 원소 수+1이 최대 레벨. 빈 목록은 최대 1레벨. 각 값은 1 이상.
- 임시값: 100 / 150 / 200 / 300 XP, 최대 5레벨.
- 각 PlantDefinition → Farming Progression → Required Farming Level: 심기 필요 레벨. 기존 아이템은 모두 1.
- Harvest Experience: **심었던 아이템**의 수확당 경험치. 씨앗은 결과 작물 대신 씨앗에서 설정. 기존 기본값 10, 0이면 경험치 없음.
- Tab 인벤토리에 현재 레벨·현재 단계 경험치/다음 필요량 표시. 최대 레벨은 MAX. 아이템 설명에 심기 필요 레벨 표시.

## 규칙

- 성장 완료 수확에만 지급. 일반 물건/변형 결과 수확, 반복 작물과 생산형의 각 실제 수확 포함.
- 인벤토리가 가득 차 바닥에 드롭되어도 정상 수확이므로 지급.
- 줍기/구매/판매/성장 완료 자체/괭이 제거/성장 전 회수 시도에는 지급하지 않음. 건물 자체 떼기는 농사 수확이 아니므로 제외.
- 낮은 레벨은 심기만 제한하며 사용/소지/거래는 제한하지 않음. 기존 성장 중 식재물의 성장과 수확에는 레벨을 재검사하지 않음.
- 기존 공유 PlantHint가 실행과 표시를 같이 제한하므로 잠긴 아이템은 심기 아이콘/초록 테두리도 나오지 않음. 가능한 도구 작업은 그대로 표시.
- 레벨 상승은 기존 Notify 알림을 재사용. 별도 해금 팝업/창 추가 없음.

## 저장과 코드

- 버전 1 PlayerSave에 farmingExperience(누적 XP)만 추가. 이전 저장의 누락 필드는 0 → 1레벨.
- 기존 맵 이동 등 자동 저장 시 함께 저장. 별도 저장 파일/수확마다 디스크 쓰기 추가 없음.
- 레벨은 설정과 누적 XP로 계산하므로 필요량을 바꾸면 다음 로드 때 레벨이 재계산됨. 최대 레벨 이후 XP도 보관(정수 최댓값까지)하여 레벨 목록 확장 시 활용.
- FarmingProgression: 경험치·레벨 계산. FarmGame.Progression: UI 조회/수확 알림 연결. FarmingSystem: 수확 성공과 심기 판정. FarmPersistence: 저장 연결.
- SetupDataValidator: 잘못된 필요 경험치/아이템 수치 거부. FarmingProgressionCheck.Run은 별도 임시 Unity 프로젝트/저장에서만 실행.
