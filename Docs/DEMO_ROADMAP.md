# 2027년 2월 입대 전 데모 개발 계획

기록일: 2026-10-21. 사용자가 승인한 개발 목록을 보존한다. 이후 작업은 이 문서를 기준으로 진행한다.

## 목표와 작업 범위

- 싱글플레이, 처음부터 끝까지 플레이 가능한 30~60분 데모.
- 2027년 2월 입대 2~3주 전 배포 가능한 상태를 목표로 한다. 정확한 입대일은 아직 확인하지 않았다.
- 맵·NPC를 대량 추가하기보다 농사 → 판매·준비 → 전투 → 귀환 흐름을 먼저 완성한다.
- 심을 대상 8~12개, 예상 밖의 변화가 분명한 사례 3~5개를 데모 목표로 잡는다.
- 12월 말 콘텐츠 추가를 멈추고 1월은 테스트·수정·배포 준비에 사용한다.
- 현재 마을 등은 임시 배치다. **농장·마을·상점·던전의 최종 배치와 이동 동선은 사용자가 그림으로 제공한다.** 그림을 받기 전 새 배치나 동선을 임의로 확정하거나 재생성하지 않는다.
