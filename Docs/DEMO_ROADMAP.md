# 2027년 2월 입대 전 데모 개발 계획

기록일: 2026-10-21. 사용자가 승인한 개발 목록을 보존한다. 이후 작업은 이 문서를 기준으로 진행한다.

## 목표와 작업 범위

- 싱글플레이, 처음부터 끝까지 플레이 가능한 30~60분 데모.
- 2027년 2월 입대 2~3주 전 배포 가능한 상태를 목표로 한다. 정확한 입대일은 아직 확인하지 않았다.
- 맵·NPC를 대량 추가하기보다 농사 → 판매·준비 → 전투 → 귀환 흐름을 먼저 완성한다.
- 심을 대상 8~12개, 예상 밖의 변화가 분명한 사례 3~5개를 데모 목표로 잡는다.
- 12월 말 콘텐츠 추가를 멈추고 1월은 테스트·수정·배포 준비에 사용한다.
- 현재 마을 등은 임시 배치다. **농장·마을·상점·던전의 최종 배치와 이동 동선은 사용자가 그림으로 제공한다.** 그림을 받기 전 새 배치나 동선을 임의로 확정하거나 재생성하지 않는다.

- 2026-10-21: 전체 지역·마을 위치 초안을 받았다. [MAP_LAYOUT_PLAN.md](MAP_LAYOUT_PLAN.md)에 원본과 해석을 기록하고, 길드·대장간·광장·주택·상점 배치, 남쪽 해안, 가벼운 빈 공간 장식, 농장↔던전 직통 연결을 적용한다. 이후 세부 크기와 시설 기능을 계속 다듬는다.

- 마을 초안 적용 확인: 네 씬 출입구 12개와 마을 접근점 13곳 통행을 검증했고, 상점 왕복과 농장↔던전 직통 이동에서 골드·소지품·작물·저장 상태 유지가 통과했다. 큰 빈 공간은 추후 시설을 위한 여유 공간으로 남겼다.

- 2026-10-21 추가 요청 반영: 마을을 40×28에서 64×44로 확장하고 주택 외관 9채(기존 포함 10채), 개별 마당·울타리·골목·화단·해안 산책길을 배치했다. 출입구 12개 연결, 마을 접근 경로 22곳, 실제 Play 상점·맵 왕복과 작물·인벤토리·골드·자동 저장 상태 유지를 검증하고 실제 Town 씬에 적용했다. 주택 실내와 새 주민 기능은 아직 없다.

- 2026-10-21 사용자 수정: 임의로 확장한 도로망을 교체하고 펠리컨 타운 지도의 배치 기준으로 Town을 64×60으로 재구성했다. 북쪽 회관·공원, 중앙 상점·광장, 남서쪽 주택가와 동쪽 강·세 다리를 기존 에셋으로 표현했다. 출입구 12개, 경로 25곳, 강 충돌과 실제 Play 왕복·거래·저장 유지 검사를 통과했다. 이전 저장 위치가 새 장애물 안에 있는 경우 안전한 시작점으로 복원하는 검사도 통과했다. 추가 건물은 외관만 있으며 새 실내·시설 기능은 보류한다.
