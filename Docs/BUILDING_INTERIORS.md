# 집·길드·대장간 내부

## 현재 구성

| 건물 | 씬 | 배치와 기능 |
| --- | --- | --- |
| 집 | FarmHouseInterior | 침대·탁자·의자·책장·벽난로·창문. 현재 가구는 장식 |
| 길드 | GuildInterior | 접수대·접수 NPC·대기 벤치·장식 게시판 |
| 대장간 | SmithInterior | 화덕·모루·무기 진열대·Rowan 상인 |

모든 실내는 별도 씬이며 `EditableMap` 아래 Floor and walls / 가구 / Residents / Travel을 Scene에서 직접 수정한다. 실내는 안전하며 낮밤 화면 어둡기는 적용하지 않는다. 시간 자체는 기존 규칙대로 흐른다.

## 출입

- 건물 앞 파란 발판에서 F로 입장하고, 실내 아래쪽 발판에서 F로 나온다.
- 길드·대장간 문은 마을의 기존 건물 자식이므로 건물 이동을 따라간다. 외부 도착 지점도 같이 조정하면 된다.
- 집 문은 집의 일부다. 수확 시 함께 사라지고 집을 다시 설치하면 생긴다. 장식 문만 남아 진입할 수 있는 상태를 만들지 않는다.
- 집을 설치할 때 앞의 출입 발판이 맵 밖이거나 장애물 안이면 설치하지 않는다.
- 집 내부는 공유되는 기본 방이다. 나올 위치는 실제로 사용한 집의 외부 위치를 기억한다. 다른 맵에 설치한 집도 해당 맵으로 돌아온다. 안에서 저장 후 재실행해도 유지된다. 돌아갈 자리가 장애물로 막혔으면 그 맵의 안전한 시작점을 사용한다.
- `GameSaveData`에 집 귀환 씬/위치를 추가했고 저장 버전은 유지했다. 기존 저장에는 값이 없어도 정상 작동하며 새 진입 때 기록된다.
- 맵 이동 전·후 자동 저장은 기존 GameSession 흐름을 사용한다.

## NPC와 상점

- 길드 접수원과 왼쪽 게시판에서 F로 의뢰 화면을 연다. 수락·던전 처치·귀환 보고로 골드를 받는다. 설정과 저장 규칙은 [길드 의뢰](GUILD_REQUESTS.md)를 참고한다.
- 대장장이 Rowan은 마을 밖에서 대장간 안으로 이동했다. 기존 무기 판매 목록과 구매·판매 가격을 복사했다. 새 강화·제작 기능은 없다.
- SmithInterior를 연 뒤 `Tools > Everything Grows > NPC 관리`에서 판매 물품·가격·대사를 바꾼다.
- 기존 거래와 동일하게 낮에 구매·판매하며 골드/공간 부족 시 구매하지 않는다. 접수 대화는 밤에도 가능하다.
- 집의 침대는 현재 시간 보내기·회복·취침 기능을 추가하지 않는다.

## 편집과 점검

`Tools > Everything Grows > World > Add house, guild and smith interiors`는 최초 배치용이다. 이미 생성된 실내나 적용 표시가 있는 외부 씬을 재생성하지 않는다. 저장하지 않은 씬이 있거나 Play 중이면 적용을 기다린다.

`Validate world connections`는 현재 11개 씬의 목적지·도착 지점·충돌·NPC 설정을 검사한다. 별도 프로젝트에서 InteriorWorldCheck.Run으로 전체 동선, 접수 대화, 대장간 거래, 이동 중 소지품/골드, 집 수확·재설치·출입을 확인한다. 이어서 InteriorWorldCheck.Resume으로 집 안 저장의 재실행과 원래 집 앞으로의 귀환을 검사한다.
