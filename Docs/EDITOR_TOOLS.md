# Unity 편집 도구

메뉴 위치는 `Tools → Everything Grows`다. 일반 관리/편집 7개, 검사 2개, 고급 5개로 정리했다.

| 메뉴 | 사용법 |
| --- | --- |
| 아이템 관리 | 모든 PlantDefinition 검색·선택. 가격/설명/성장 유형/수량/시간/레벨/경험치/무기 수치를 기존 조건부 Inspector로 편집. 에셋 자동 저장, Undo 가능 |
| NPC 관리 | 씬 선택 후 NPC 프로필 검색. ID/이름/대사/상점/접수 기능/품목·가격 편집. 연결된 실제 NPC 확인. 프로필 추가는 캐릭터를 배치하지 않음 |
| 몬스터 보상 관리 | 공유 종류 검색, 골드/드롭 편집과 새 종류/복제. 에셋 자동 저장 |
| 길드 의뢰 | 목록 검색, 의뢰 ID/설명/목표 씬·적/수량/보상/반복 여부 편집·추가. 기존 ID 유지, 에셋 자동 저장 |
| 맵 연결 관리 | 씬별 출입구/도착점 목록·검색. 기존 Inspector로 목적지/도착 ID/접촉·우클릭/층 클리어 조건 편집. Scene에서 대상 선택, 개별/전체 연결 검사 |
| 맵 배치 | 기존 Scene 프리팹 배치 도구 |
| 플레이어 조작 설정 | 기존 PlayerControls 에셋 선택 |
| 검사 / 프로젝트 설정 검사 | 기존 전체 설정 검사 |
| 검사 / 맵 연결 검사 | 기존 전체 맵 연결 검사 |
| 고급 / 저장용 아이템 목록 갱신 | 기존 GUID 기반 저장 목록 갱신 |
| 고급 / 현재 맵 저장 ID 준비 | 기존 건물/적 배치 ID 준비 |
| 고급 / 현재 씬 빌드 등록 | 현재 씬 빌드 활성화 |
| 고급 / 배치 프리팹 생성 | 기존 출입구/도착점 프리팹 생성 |
| 고급 / 장애물 프리팹 생성 | 기존 장애물 프리팹 생성 |

## 씬 편집과 저장

- NPC/맵 창은 선택한 씬이 닫혀 있으면 **선택한 씬 열기**를 눌러 추가로 연다. 다른 씬을 닫거나 미저장 작업을 버리지 않는다.
- 씬 데이터 변경은 Undo 가능하며 씬을 수정 상태로 표시한다. **이 씬 저장**을 눌러 저장한다. 그 씬의 다른 미저장 편집도 함께 저장되는 일반 Unity 씬 저장이다.
- NPC의 시작 골드는 새 시작의 초기값이며, 기존 저장의 보유 골드를 덮어쓰지 않는다.
- 맵 연결의 개별 검사는 목적지 씬의 현재 열린 내용을 우선한다. 닫힌 목적지는 임시 미리보기 씬으로 읽고 닫으며 원본 파일을 저장하지 않는다.
- 전체 연결 검사는 기존 충돌/도착점/연결 검사를 재사용한다. 검사 결과와 구체적인 오류는 Console에서도 확인할 수 있다.
- Play 중 데이터 편집/추가/씬 열기/저장을 차단한다. 런타임 저장 데이터와 씬 에셋의 설정 편집은 별개다.

## 제거한 메뉴와 코드

초기 씬/농장/농사 설정, 예전 전투 테스트 연결, 예전 마을 배치들, 월드/실내/병원/탑의 일회성 생성, 이미 끝난 정리 작업 등 20개를 메뉴에서 제거했다. 다른 작성 함수와 격리 검사가 사용하는 정적 함수/파일은 유지한다. 원본 씬/에셋/저장 ID를 삭제하거나 배치를 재생성하지 않는다. 맵 배치 창의 편집용 맵 연결 기능도 유지한다.

## 코드와 검사

- ItemManagerWindow는 기존 PlantDefinitionInspector를 임베드하여 성장 설정을 중복 구현하지 않는다.
- NpcManagerWindow는 기존 NpcManager의 직렬화된 프로필 목록을 편집한다. 상품 기본 판매가는 아이템 관리에서 편집한다.
- GuildQuestWindow는 기존 GuildQuests 에셋을 편집한다. 이미 수락한 의뢰의 스냅샷 규칙은 그대로다.
- MapConnectionsWindow는 기존 MapExitInspector/MapArrivalInspector와 WorldConnectionValidator를 사용한다.
- ManagementEditorUI는 씬 선택/저장 버튼/검색/오류 표시만 공유한다. 자동 씬 저장이나 자동 씬 닫기 기능은 없다.
- 격리 전용 ManagementToolsCheck.Run은 메뉴 중복/누락, 아이템 검색/Undo, 의뢰 오류, NPC Undo, 도착점 검사·미저장 작업 보존과 실제 네 창의 GUI 렌더 오류를 검사한다.
