# 필드 채집물

2026-10-27 적용.

## 설정·배치
- Tools > Everything Grows > 아이템 관리 > **채집물 설정**에서 종류를 검색/추가하고 획득 아이템, 수량, 재생 여부, 전량 획득 후 재생 시간(초)을 편집한다. 에셋 변경은 자동 저장·Undo를 지원하고 Play 중 수정은 차단한다.
- **현재 씬에 배치**를 누르면 활성 맵의 Scene 뷰 중심에 채집 지점을 추가한다. Scene에서 위치·크기를 조정하고 씬을 직접 저장한다.
- 기존 FarmItemPlacement의 Forage에 종류를 연결해도 된다. Forage가 있으면 그 설정이 Item보다 우선하며, 비우면 기존 단순 바닥 아이템이다. 같은 종류 에셋을 여러 지점이 공유해도 지점별 수량·대기 상태는 독립적이다.
- 맵 배치 도구와 채집물 창으로 배치한 지점에는 고유 MapObjectId를 부여한다. Hierarchy에서 복제했다면 고급 > 현재 맵 저장 ID 준비를 실행한다. 중복 ID는 Play 전 검사에서 안내한다. 저장을 유지하려면 ID를 임의로 바꾸지 않는다.
- 숲에 예시 지점 두 개를 한 번 추가했다. StoneFragments는 돌 조각 3개, 재생 60초. CloudFind는 구름 1개, 재생하지 않는 일회성이다. 기존 배치와 보스는 유지한다. 에디터 시작 때 재생성하지 않는다.

## 획득·재생
- 기존 우클릭 바닥 아이템 줍기를 그대로 사용한다. 들어갈 수 있는 수량만 인벤토리에 넣고, 가방에 못 담은 수량은 같은 지점에 남긴다.
- 전량을 주운 시점부터 재생 대기를 시작한다. 일부만 주웠다면 재생 타이머를 시작하지 않는다.
- 재생은 낮/밤에 관계없이 게임 내 시간으로 진행한다. 다른 맵에 있어도 진행하며 메뉴 일시정지·게임 종료 중 현실 시간은 계산하지 않는다.
- 오래 비웠어도 한 묶음만 준비하고 여러 회차의 수량을 누적하지 않는다.
- 일회성 지점은 획득 후 맵 이동/이어하기로 다시 생기지 않는다. 재생을 끈 지점을 나중에 재생형으로 바꾸면, 비어 있는 지점에 새 대기 시간을 부여한다.
- 플레이어가 버린 물건·전투 드롭·일반 기존 바닥 아이템은 채집 지점이 아니다. 같은 아이템이어도 재생되지 않는다. 주운 물건을 다시 버려도 출신 채집 지점의 재생 권한을 갖지 않는다.
- 채집은 기존 바닥 줍기이므로 농사 수확 경험치를 지급하지 않는다.

## 저장·실패 처리
- 버전 1에 optional MapSave.forageNodes를 추가한다. 지점 ID, 현재 묶음의 아이템 저장 ID, 남은 수량, 전량 획득 기록, 재생 예정 게임 시각을 저장한다.
- 채집물의 그림은 일반 PieceSave 목록에 중복 저장하지 않는다. 맵 복원 시 지점 상태에서 다시 만든다.
- 기존 저장에는 빈 채집 상태 목록을 허용하고, 새로 추가한 지점만 초기 수량으로 시작한다. 기존 일반 바닥 아이템을 채집물로 강제 전환하지 않는다.
- 획득 후 자동 저장한다. 저장 실패 시 인벤토리와 지점 수량/타이머를 이전 상태로 되돌린다. 가방이 꽉 차 하나도 얻지 못하면 지점을 소모하지 않는다.
- 현재 묶음은 기존 아이템/남은 수량을 보존하며 설정 변경은 다음 재생 묶음에 반영한다.

## 코드
- ForageDefinition: 종류별 공유 설정.
- ForageSystem: 지점별 수량/재생 시각, 획득 트랜잭션, 저장·복원.
- FarmGame.World: 기존 바닥 아이템 그림/판정 재사용. forageId가 있는 조각의 획득만 ForageSystem으로 위임한다.
- FarmPersistence: 일반 조각과 채집 지점의 저장 구분.
- ForageWindow: 관리/배치 UI. PlacementInspectors와 MapPlacement는 기존 배치 흐름을 확장한다.
- ForageExampleSetup: 숲 예시의 명시적 일회 작성. 사용자 씬을 주기적으로 생성하거나 다시 만들지 않는다.
- ForagingCheck.Run: 임시 프로젝트/WTF_SAVE_TEST_DIR에서 부분·가득 찬 가방, 전량 획득 시각, 저장 실패 복구, 일회성 보존, 실제 맵 왕복과 야간 원격 재생, 일반 드롭 분리를 검사한다.
